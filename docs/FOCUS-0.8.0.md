# Режим фокуса 0.8.0

## Использование

Настройки → Режим фокуса → Включить. Одна страница вместо навигации. Наставник принимает текст и аудио WEBM/WAV/MP3; запись с микрофона запрашивает разрешение. Оценки сохраняются сразу, «Исправить» открывает исходный текст и распознанные поля. Для изменения смысла записи можно попросить наставника исправить конкретный факт. Выход — кнопкой внизу, данные остаются в основных разделах.

Цели накоплений и числа тренировок задаёт пользователь. Срок не ограничен. Прирост баланса — доходы минус расходы после выбранной даты, не отдельный накопительный счёт. Вес показывается как динамика фактических измерений. Сон поддерживает два времени, одно известное время или только длительность.

## Питание

Калории, белки, жиры, углеводы, общий сахар, клетчатка и витамины A, B1, B2, B3, B5, B6, B9, B12, C, D, E, K относятся к съеденной порции. Сахар входит в углеводы. Нет данных — неизвестное значение, а не ноль. Статистика суммирует записанную еду; неполный дневник не выдаётся за полный дневной рацион. Витамины разворачиваются отдельно, единицы закреплены в общей схеме. Нормы, проценты дефицита и диагнозы из оценок не выводятся.

Для двух типовых продуктов используются ориентиры USDA: готовая куриная грудка без кожи/масла (FDC 171477) и варёный белый рис (SR 20451). Рецептура может отличаться. Прочие продукты оценивает модель с пояснением допущений. Взвешенная порция сама по себе не делает состав точным. Без веса сохраняется предположение о порции в комментарии, поле фактической массы остаётся неизвестным. Для уточнения можно вводить состав с этикетки.

Наставник — Claude Sonnet 4.6, спокойный личный помощник без Drill Sergeant. Пользовательские тексты и комментарии передаются как данные. Модель получает историю приложения, комментарии финансов, дневник, еду, активности и последние сообщения. Точные записи по запросу охватывают до 90 дней; за более долгий срок есть агрегаты с начала отслеживания. Недостающие данные явно отделены от нулей.

## Сохранность

Схема 12: mentor_turns, food_entries, activity_entries. Перед миграцией SQLite сохраняет копию. Новые таблицы включены в резервные копии и синхронизацию. Обновите все устройства одного профиля перед использованием режима: старый клиент не может перезаписать данные более новой схемы.

Сохранение фактов и разговора — одна транзакция. Повторный запрос сохранения с тем же ID не создаёт дубли. Исправление откатывает прежние связанные значения только при совпадении отпечатков; более свежие ручные/удалённые/изменённые на другом устройстве записи защищены. При ошибке местного сохранения повторная попытка использует уже оплаченный ответ модели.

## Проверка

242 теста приложения, 24 серверных теста. Проверены миграции, копии, неизвестные суммы, исправления и повторное сохранение, состав еды, неизвестные нутриенты, старые статусы вакансий. Шесть реальных запросов OpenRouter на вымышленных данных: день, исправление, неделя, неизвестная порция, планы/отрицание, неизвестная цена. Суммарная стоимость успешного набора — $0.166161. Ограничения схемы Anthropic устранены без отключения проверки данных.

Просмотр в скрытом браузере 1440×900 и 393×852: оригинальная тема, одна страница, питание, настройки; нет горизонтального переполнения или ошибок JavaScript. Собранный Windows app.asar запущен в Electron с изолированной базой: настоящее IPC, SQLite, вход/выход режима, исправление, КБЖУ/витамины, месячная цель и четыре счётчика вакансий. APK 0.8.0 / код 33, прежняя подпись. Физический микрофон Android и фоновые уведомления на устройстве в эту проверку не входили.
