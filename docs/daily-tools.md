# Уход и инструменты дня

Выпуск 0.6.0 для Windows и Android.

- **Здоровье → Уход и привычки.** У каждого пункта можно выбрать группу. Для ежедневного пункта с отметкой «да / нет» можно добавить до восьми отдельных выполнений, их время и напоминания. Утро и вечер отмечаются независимо; общая цель выполнена только после всех отметок. Старые записи сохраняются и не превращаются автоматически в новые выполнения. Бытовые обязательства остаются в делах дня.
- **Сегодня → Утро / Вечер.** Настраиваемая последовательность коротких шагов: подъём, вес, уход, привычки, вечерний вопрос, запись дня. Пропуск шага ничего не записывает. Отметки используются в общей статистике.
- **Сегодня → Фокус.** Интервал или секундомер, с привязкой к делу или своим названием. Пауза не входит в рабочее время. Закрытие приложения не останавливает запущенную сессию; завершить её нужно вручную. Сессия не закрывает дело автоматически.
- **Финансы → Платежи.** Еженедельные, ежемесячные и ежегодные обязательства. Предстоящие суммы показываются отдельно от расходов. Кнопка «Оплачено» открывает подтверждение суммы, даты, счёта и категории; расход создаётся только после него. Повторное подтверждение одного платежа не создаёт второй расход. Изменение шаблона применяется к новым платежам; созданные ранее сохраняют условия, сумму можно уточнить при оплате.
- **Здоровье → Эксперименты.** Своя перемена на 3–90 дней, ежедневные отметки и сравнение записанных показателей с равным по длительности участком предыдущего периода. Это сравнение записей, а не доказательство причин. Дни без измерений не превращаются в нулевые значения.
- **Журнал / Дневник → Вопрос вечера.** Один вопрос на день, с необязательным ответом. Записанный вопрос сохраняется вместе с ответом. Наставник получает ответы, отметки ухода, завершённые сессии фокуса и эксперименты в обзорах дня и недели.

Разбор текста может предложить отдельное выполнение ухода, если оно однозначно названо. Неопределённое упоминание не засчитывает все выполнения; каждое предложение подтверждает пользователь.

Напоминания ухода соблюдают тихие часы и разрешения устройства. На Android для уведомлений при закрытом приложении нужны разрешения на уведомления; ограничения энергосбережения конкретного телефона могут влиять на доставку. На Windows NEXUS должен работать.

Схема данных — 11. Перед миграцией существующей базы создаётся резервная копия. Обновите приложение на всех устройствах: предыдущая версия не сможет записывать поверх новых данных. Для собственного сервера сначала обновите серверные модули из этого выпуска.
