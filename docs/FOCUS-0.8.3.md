# Фокус 0.8.3: сохранение настроек

Форма прежде сохранялась только по кнопке и читала настройки один раз при монтировании. Android мог показать кеш до загрузки свежей серверной базы; поздняя синхронизация не обновляла форму. Windows выполнял webContents.reload при принятии серверных изменений, что сбрасывало незавершённый ввод.

Теперь updateConfig — типизированный частичный patch с валидацией и транзакцией на обеих платформах. Отсутствующий dietNote не получает пустой default. Автосохранение через общую очередь: 350 мс, blur, уход со страницы и ожидание очередей при закрытии Windows. Настройки заблокированы до первого чтения; новые snapshot/revision/event обновляют форму, сохраняя локальные грязные поля. Полная перезагрузка Windows заменена событием обновления данных. Совместимые JSON-строки focusConfig объединяются по полям; конфликт одного поля решается существующими часами редактирования. База остаётся версии 14.

Старый таймер/секундомер и dock больше не присутствуют в Today и оболочках Windows/Android. Исторические таблицы и API оставлены для совместимости резервных копий; пользовательские записи не удаляются. Новый изолированный наставник и ручной перенос в основной NEXUS продолжают работать.

Проверено: 276 тестов приложения, 26 серверных тестов; скрытые Windows/Android проверки автосохранения и перезахода. Настоящий Windows app.asar закрыт до debounce после события серверного обновления; отдельный повторный процесс открыл ту же SQLite и восстановил модель, текст и денежную цель. APK имеет versionCode 36 и прежнюю подпись. Физический Android не использовался.
