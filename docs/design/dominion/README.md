# Доминион 3.0 — реализация

Дата проверки: 04.10.2026. Основа: `d919d8e2b29748ac46d094cd8533be2c68d71653`.
Публикация разрешена пользователем 04.10.2026. Версия к выпуску — **0.7.0**.
Результаты ниже относятся к проверенной реализации; установщик Windows и APK собираются из того же дерева с новой версией.

## Что реализовано

- «Оформление» в настройках: Стандартная / Доминион, две карточки с radio и миниатюрами.
- Default — standard. Ключ `nexus.appearance.theme.v1` хранится только на устройстве, вне предметных резервных копий.
- Переключение внешнего store через `useSyncExternalStore`, без смены React key, reload или remount приложения.
- Изолированный `dominion.css`, стальные поверхности, красный акцент действий, отдельные цвета результата, предупреждения и информации.
- Пять существующих маршрутов Windows и шесть разделов Android; пользовательский текст, даты фильтров и идентификаторы сохранены.
- 213 контекстных словарных ключей в 31 области. Полный перечень: [copy-keys.json](copy-keys.json). Рабочий источник — `NEXUS/src/renderer/appearance-copy.ts`.
- Кириллический прототип Sector Dominion только для коротких заголовков экранов; основной шрифт для NEXUS, цифр, сумм, полей и записей.
- Единые MetricDelta для веса и сна: предыдущая валидная запись, предметная дата, направление отдельно от оценки, нейтральный округлённый ноль. Логика существующей цели поддержана, новая форма целей не добавлена.
- Графики с реальными временными расстояниями, разрывами, видимой шкалой, честным нулём и отрицательными столбцами. Подписи шкалы и инспекции используют одинаковые единицы, включая валюту. Range, hover, tap, click и Escape поддержаны; выбор сохраняется при смене темы.
- Android: адаптивная нижняя навигация, SVG-иконки, 48 px основные touch targets, `data-no-swipe` графиков, стальной fallback, системный textZoom и Back для открытой поверхности.
- Native feedback после принятой отметки и реальной смены темы; системное отключение тактильности учитывается. На вводе текста, прокрутке, синхронизации и просмотре точек импульсов нет. Reduced motion отключает перемещения и анимацию.

API, сервер, предметная схема, финансовые расчёты и AI-персональность не изменялись.

## Ресурсы

[resources.json](resources.json) содержит происхождение, размер и SHA-256 шрифта.
Шрифт занимает 6 620 байт. CITY/MACHINE используют предусмотренное стальное резервное оформление: production-арты в комплекте не выбраны. Файлы `reference_only`, внешние hotlink-фоны и сгенерированные сцены не включены.

## Оставшиеся проверки на устройстве

1. На тестовом Android установить candidate APK, включить крупный системный шрифт и TalkBack. Пройти шесть разделов в обеих ориентациях; открыть запись с клавиатурой и проверить вырезы/нижний inset.
2. С отключённой системной тактильностью сменить тему и подтвердить отметку: вибрации быть не должно. После включения — максимум один короткий импульс. Прокрутка и выбор точки графика не вибрируют.
3. Back сначала закрывает открытый tooltip/диалог, затем сохраняет обычное поведение приложения. Проверить возврат фокуса после закрытия.
4. На Windows включить Narrator, проверить 125/150/200% системную DPI и 200% zoom; проверить компактную навигацию, доступные даты и значения, отсутствие непрерывного озвучивания hover.
5. Во время реальной голосовой записи сменить оформление и завершить запись: запись должна продолжиться в том же компоненте.

Для воспроизведения расчётов и состояния темы: `npm ci`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run build` в NEXUS. Для APK — `npm run android:sync`, затем `gradlew assembleDebug` с JDK 21 и Android SDK. Публикация и повышение версии требуют отдельного поручения по приложенному Executor Prompt.

## Повторная сверка после выпуска 0.7.0

При сопоставлении с Executor Prompt и главами спецификации обнаружены и исправлены в 0.7.1:

- Подписи вечернего вопроса в составе и текущем шаге процедуры, поле воспоминания в разборе журнала и сообщение о сохранении досье теперь используют контекстный словарь.
- Доступное имя MetricDelta включает словесное направление и оценку (благоприятное/неблагоприятное/нейтральное), а не только знак, величину и дату. Добавлена проверка противоположных оценок при явной цели.
- Область касания ползунка Android была меньше заданной. По последующему прямому указанию пользователя 04.10.2026 все слайдеры графиков удалены в обеих темах и платформах. Это согласованное изменение требования сохранять range-контрол: выбор доступен на графике по наведению/касанию и с клавиатуры (стрелки, Home/End, Escape).

Инвентаризация текста сверена статически с исходным словарём. Исходные названия реестра/навигации намеренно сохранены и тематизируются при показе. Ошибка пустого ввода журнала сохранена как существенная причина отказа. Начальные тексты пользовательского напоминания не переименовываются при смене темы.

Ограничения прежней матрицы остаются: NOT RUN для физического Android, TalkBack, Narrator, системного DPI, реальной записи голоса и измерения long tasks/плавности на Android среднего класса. CP01 означает пройденные перечисленные сценарии, а не полный перебор каждого сочетания empty/loading/error/длинных и плотных данных во всех поверхностях. Полную приёмку без этих проверок считать завершённой нельзя.
