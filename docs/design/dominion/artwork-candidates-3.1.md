# Арты StarCraft для Доминиона

## Разрешение в дизайне

При желании можно использовать настоящие арты StarCraft: Корхал / Августград, терранскую технику, имперскую гвардию и персонажей. Это прямо предусмотрено разделом 21 PDF 3.1 и разделом «Происхождение графики» Executor-Prompt-3.1; пользователь повторно подтвердил направление.

Арты служат отдельными акцентами вокруг интерфейса. Формы, цифры, графики и записи лежат на непрозрачных спокойных поверхностях. Стальная конструкция сохраняется без изображения. ИИ-города, техника, персонажи и сцены не используются.

## Подборка

Источники проверены 04.10.2026. Ниже — подборка. Для выпуска 0.7.3 пользователь одобрил отдельную визуальную пробу с другим артом Thor: [источник выбранного изображения](https://www.goodfon.com/games/wallpaper-badfon-starcraft-terran-tor-meh.html). Этот файл включён локально в шапку «Сегодня»; он не приписывается Peter Lee. Остальные кандидаты не включены.

| Вариант | Источник | Применение |
| --- | --- | --- |
| Starcraft Thor, Peter Lee | [Конкретная работа в портфолио автора](https://peterconcept.artstation.com/projects/rRo0BJ) | Иллюстрация для MACHINE: тяжёлая техника, красно-серая броня. Только отдельный кадр в шапке или боковой акцент. |
| Starcraft Battleground Loading Screen, Peter Lee | [Конкретная работа в портфолио автора](https://peterconcept.artstation.com/projects/5EyKz) | Полноценная иллюстрация окружения для загрузочного экрана Heroes of the Storm. Кандидат для широкого акцента; не выдавать за изображение Корхала. |
| Менгск за трибуной | [Иллюстрация в официальном материале Blizzard](https://news.blizzard.com/de-de/article/10022941/antworten-auf-eure-starcraft-ii-creative-development-fragen-teil-2) | Кандидат для наставника: красная гвардия и имперские знамёна. |

Ранее предложенные портфолио Thiago Klafke и Martin Holmberg показывают модели и рендеры игрового окружения. Они могут служить справочником материалов и архитектуры, но не подходят как подборка полноценных иллюстраций. Рекомендация использовать их как готовые арты отозвана.

Для первого акцента предлагается Thor; Менгск — отдельный вариант у наставника. На телефоне использовать небольшой кадр только в шапке, без постоянного рисунка за карточками. Точный арт Корхала пока не выбран.

Для включённого Thor источник, размер и SHA-256 зафиксированы в `resources.json`, уведомление о сторонних правах — в `NEXUS/src/renderer/assets/THIRD-PARTY-ART.md`. Автор этой конкретной иллюстрации не подтверждён. Разрешение использовать арт в дизайне не означает, что стороннее изображение становится MIT-кодом.
