# Арты StarCraft для Доминиона

## Разрешение в дизайне

При желании можно использовать настоящие арты StarCraft: Корхал / Августград, терранскую технику, имперскую гвардию и персонажей. Это прямо предусмотрено разделом 21 PDF 3.1 и разделом «Происхождение графики» Executor-Prompt-3.1; пользователь повторно подтвердил направление.

Арты служат отдельными акцентами вокруг интерфейса. Формы, цифры, графики и записи лежат на непрозрачных спокойных поверхностях. Стальная конструкция сохраняется без изображения. ИИ-города, техника, персонажи и сцены не используются.

## Подборка

Источники проверены 04.10.2026. Это подборка для выбора, файлы не включены в приложение.

| Вариант | Источник | Применение |
| --- | --- | --- |
| Корхал: небоскрёбы и платформы, Thiago Klafke | [Авторское портфолио Legacy of the Void](https://www.thiagoklafke.com/blog/portfolio/starcraft-ii-legacy-of-the-void/) | Основной кандидат CITY: узкий городской фрагмент в верхней части экрана. Стальной фон, индустриальные формы, подсветка окон. |
| Корхал: жилые здания, Martin Holmberg | [Starcraft LOTV Terrans — авторское портфолио](https://martinholmberg.artstation.com/projects/ykZlx3) | Альтернатива CITY с менее помпезной архитектурой; подходит для бокового акцента. |
| Менгск и Королевская гвардия | [Официальный материал Blizzard о командире](https://news.blizzard.com/en-us/article/23185584/new-co-op-commander-arcturus-mengsk) | Кандидат MACHINE и небольшой акцент у наставника. Красные пластины и тяжёлая техника поддерживают текущую тему. |

Я бы начал с одного городского фрагмента Корхала на широком экране. На телефоне — небольшой кадр только в шапке, без постоянного рисунка за карточками. Портрет Менгска оставить отдельной опцией для наставника, чтобы основной интерфейс не превращался в галерею.

Для выбранного файла потребуется зафиксировать оригинальный URL, автора, условия использования, размеры, итоговый SHA-256 и локальную оптимизированную версию. Разрешение использовать арт в дизайне не означает, что стороннее изображение становится MIT-кодом. Сейчас в открытые исходники добавлены только ссылки и разрешённая рамка из пользовательского UI-комплекта.
