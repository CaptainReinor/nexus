# Фокус 0.8.5

## Контекст

Инструкции вынесены в `focus-prompt.ts`, сокращены с 13 837 до 7 957 символов и согласованы с действующей схемой: новые ID и неизвестные nullable-поля опускаются. Сохранены смешанные исправления/вопросы, отмена дублей, абсолютная доля полного рецепта, приоритет упаковки, раздельные накопления, изоляция основного NEXUS и различие оценок питания от известных данных.

`focus-context.ts` проецирует предметные данные без отметок обновления, сериализованных JSON-строк и прочих полей хранения. Витамины и источники приходят структурированно. `prepared` содержит только отличия полного ингредиента от съеденной порции; полные значения восстанавливаются как `{...food, ...food.prepared}`. Текущие порции, неизвестные нутриенты, источники и ID сохраняются. Число реплик (12) и окно подробных записей (обычно 28 дней, до 90 по запросу) не сокращаются. История и база на устройстве не меняются.

## Проверки

292 локальных теста приложения, проверки типов, линтер, сборки Windows/Android. Дополнительное покрытие проверяет восстановление полного рецепта при долях 1, 1/2, 2/3, неизвестность клетчатки, источники нутриентов, комментарии расходов, историю и ссылки на удалённые продукты, а также совместное исправление состава, изменение доли и пополнение накоплений.

Реальная проверка Gemini 3.8 Flash выполнена только на вымышленных данных: 16 сценариев, 17 запросов с одной намеренно внесённой ошибкой для проверки восстановления. Встроенная проверка бюджета перед каждым запросом резервирует верхнюю оценку и останавливает дальнейшие обращения при неизвестной стоимости. Общий лимит пользователя $1, фактические расходы $0.103641.

Сравнение с предыдущим прогоном тех же сценариев: вход 150 624 → 113 086 токенов (−24.9%), стоимость $0.132523 → $0.103641 (−21.8%). Ответы модели и её кеширование различаются между прогонами; это результат проверенного набора, не гарантия экономии для каждого сообщения.

## Интерфейс

Enter отправляет сообщение; Shift+Enter оставляет перенос строки. Composition, клавиша 229, удерживание Enter и текущая запись голоса не запускают отправку. Действующий предохранитель защищает от повторного запроса до завершения сохранения. Кнопка «Начитать» получает отдельный контрастный фон, обводку и цвет текста; отключённое состояние остаётся приглушённым.

Схема данных остаётся 15. Версия Android 38.
