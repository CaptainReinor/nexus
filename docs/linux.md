# Linux: переносной NEXUS

Сборка x86_64 предназначена для обычного 64-битного ПК. Интерфейс Cinnamon с Xorg поддерживается. Для первой версии ориентируемся на Linux Mint 22; проверка GitHub Actions проходит на Ubuntu 22.04, а запуск на конкретном компьютере проверяет пользователь.

## Запуск без установки приложения

1. Скачать `NEXUS-0.4.5-linux-x64.AppImage` из Releases и положить в постоянную папку.
2. В свойствах файла, на вкладке «Права», разрешить выполнение как программы.
3. Запустить файл двойным щелчком.

Установка NEXUS через менеджер пакетов не требуется. База и настройки по умолчанию сохраняются в пользовательской папке конфигурации, а не внутри AppImage. Новый файл приложения не стирает их. Для подключения к своему серверу ввести его адрес и приглашение.

Если требуется переносить и базу рядом с приложением, перед первым запуском можно создать папку `NEXUS-0.4.5-linux-x64.AppImage.config` рядом с файлом. При смене имени AppImage переименуйте эту папку соответственно. Ключи привязаны к системной связке ключей: на другом ПК нужно подключиться заново. Документация формата: https://docs.appimage.org/user-guide/portable-mode.html.

## Если система сообщает об отсутствии FUSE

Это зависимость формата AppImage, а не установка NEXUS. Можно распаковать файл и запустить приложение без FUSE:

```bash
chmod +x NEXUS-0.4.5-linux-x64.AppImage
./NEXUS-0.4.5-linux-x64.AppImage --appimage-extract
./squashfs-root/AppRun
```

## Связка ключей и защита

Ключи ИИ и синхронизации хранятся через Electron safeStorage и системную связку ключей. Если она отсутствует или заблокирована, приложение просит её разблокировать. Небезопасный `basic_text` не используется. Обычные локальные записи доступны без подключения ИИ и сервера.

Сборка сохраняет изоляцию renderer и Chromium sandbox. При ошибке `No usable sandbox` не запускайте с `--no-sandbox`: пришлите текст ошибки и версию Mint, чтобы проверить настройки AppArmor/пространств имён именно на этой системе.

Автозапуск создаётся только при включении соответствующей настройки. Для AppImage он ссылается на исходный файл, поэтому после перемещения файла или обновления с новым именем выключите и снова включите автозапуск.

## Сборка

На Linux из `NEXUS`:

```bash
npm ci
npm ci --prefix ../NEXUS-Android --ignore-scripts
npm run dist:linux
```

Модуль SQLite пересобирается для Linux и версии Electron. Workflow `Linux portable` также проверяет запуск упакованного приложения, доступ к настройкам и запись/чтение SQLite в отдельном тестовом профиле. Платные запросы ИИ не выполняются.
