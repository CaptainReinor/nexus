# Изменения

## Windows / Android 0.8.5 — 13.10.2026

- Контекст наставника компактнее: убраны повторные инструкции, технические поля и дубли питания. Полный рецепт передаётся только через отличия от съеденной порции.
- Сохранены история диалога, комментарии к операциям, сведения об удалённой еде и данные периода для итогов.
- Enter отправляет сообщение наставнику, Shift+Enter переносит строку. Ввод через подсказки клавиатуры и повторное нажатие не создают лишний запрос.
- Активная кнопка «Начитать» получила более контрастное оформление.

## Windows / Android 0.8.4 — 13.10.2026

- Скрытая личная база часто употребляемых продуктов: единые названия, значения на 100 г, бренды и способы приготовления.
- Повторные записи используют сохранённое КБЖУ, сахар, клетчатку и витамины. Данные пользователя приоритетны; оценки витаминов остаются приблизительными.
- Каталог синхронизируется внутри профиля и остаётся отдельным от основной части NEXUS.
- Фокус получил тёмный дизайн на основе выбранной «Бумаги»: мягкие карточки, спокойные цвета и новая типографика.

## Windows / Android 0.8.3 — 13.10.2026

- Настройки наставника и целей фокуса сохраняются автоматически и восстанавливаются после перезапуска; закрытие окна ожидает завершения локального сохранения.
- Форма получает актуальные настройки после синхронизации, сохраняя незавершённые правки. Изменения отдельных полей не обнуляют остальные.
- Независимые изменения настроек на ПК и Android объединяются; для одного поля приоритет более свежего значения.
- Получение данных с сервера обновляет интерфейс без полной перезагрузки и потери текущего ввода.
- Старый фокус с таймером удалён из основного интерфейса Windows и Android. Режим с наставником сохранён.

## Windows / Android 0.8.2 — 13.10.2026

- Отдельные накопления в фокусе: пополнение, снятие, график и фактический прогресс цели без завышения доходами.
- Исправления и вопросы наставнику поддерживаются в одном запросе; контекст связан с действительными ID сохранённых записей.
- Настоящее удаление еды через наставника и кнопку в списке питания. Старые обнуления по явно записанной просьбе удалить приводятся к фактическому удалению.
- Доля готового блюда пересчитывает массу, калории, КБЖУ, сахар, клетчатку и витамины от исходного рецепта; исправление доли не масштабирует её повторно.
- Распознаются «гр» и другие сокращения массы; уточнение состава не теряет известную массу.
- Наставник по умолчанию использует протестированный Gemini 3.8 Flash вместо Sonnet; переход с прежней модели выполняется при обновлении.
- Подробная диагностика, одна ограниченная попытка исправить неверный ответ; статусы ошибок Android записываются корректно.

## Windows / Android 0.8.1 — 13.10.2026

- Режим фокуса начинает отдельную историю: наставник и статистика не читают основную базу NEXUS.
- Перенос веса, сна, денег и тренировок в основной NEXUS — только кнопкой «Передать данные в NEXUS» в настройках фокуса. Повторный перенос не дублирует операции.
- Старые записи и ответы сохранены в резервной копии, но не входят в новую историю фокуса.
- Убраны лишние подписи; статистика работы: «Отказы после отклика» и «Отказы после собеседования».

## Windows / Android 0.8.0 — 12.10.2026

- Новый бессрочный режим фокуса: одна страница, разговор с наставником, голос/текст, автоматическая запись и исправления. Цели задаёт пользователь.
- Статистика веса, сна, денег, питания и активностей; КБЖУ, общий сахар, клетчатка и витамины с оценками и неизвестными значениями. Вкусовые предпочтения в настройках наставника.
- Наставник Claude Sonnet 4.6 обращается к истории, даёт дневные и периодические итоги; запрос итогов не создаёт повторных записей.
- Настройки сгруппированы; переключение тем временно выключено, возвращена исходная тема. Стрелки изменения показателей и интерактивные графики доступны в ней.
- Работа: четыре счётчика, основные статусы, новые вакансии «Не отправлен». Месячная цель откликов перенесена в работу. Исторические статусы сохранены и отображаются через упрощённые названия.
- Схема данных 12. Перед миграцией сохраняется резервная копия. Сервер поддерживает новые таблицы и строгий формат ответа ИИ.

## Windows / Android 0.7.8 — 12.10.2026

- Вакансии можно полностью удалить с подтверждением. Удаляются история, связи с кейсами и результаты ИИ; сами кейсы и опыт остаются.
- Повторная отправка формы во время сохранения не создаёт ещё одну вакансию.
- Удаления синхронизируются; запоздалые дочерние записи без вакансии убираются при объединении данных.
- Ответ ИИ для вакансии, удалённой во время запроса, не сохраняется; стоимость запроса учитывается.
- Убраны скрытые ограничения списка вакансий и истории, обрезавшие статистику. Сортировка по времени изменения стабилизирована.
- Обновление сервера не требуется.

## Windows / Android 0.7.7 — 12.10.2026

- Разбор вакансий отделяет формат работы от занятости и графика: офис, удалённо, гибрид, разъездной. Явно указанный формат в исходном тексте имеет приоритет; неизвестный не выдумывается.
- Найденные поля показываются перед применением. Можно выбрать, что заполнить; ручные правки, сделанные во время запроса, сохраняются.
- Ответ от прежнего текста или закрытой формы не применяется к другой вакансии.
- Добавлено редактирование валюты зарплаты и проверка её границ. Односторонняя зарплата не объединяется со старой противоположной границей.
- Android: раздел «Работа» упрощён до просмотра вакансий, архива и смены статуса. Создание, редактирование, опыт и ИИ-разбор доступны на ПК. Данные опыта и вакансий сохранены.
- Обновление сервера не требуется.

## Windows / Android 0.7.6 — 06.10.2026

- Графики веса и инвестиций продолжаются последним известным значением в дни без записи, вплоть до сегодня. Сохранённые измерения и расчёты не меняются.
- Android: ручной ввод времени сна доступен в «Здоровье» и «Сегодня»; обе отметки сохраняются одной кнопкой.
- Android: проверяется разрешение канала уведомлений, добавлены тестовое уведомление и переход в системные настройки. Расписание восстанавливается при возврате в приложение.
- Ошибки настройки уведомлений показываются в интерфейсе. Ограничения экономии батареи видны в настройках.
- Обновление сервера не требуется.

## Windows 0.7.5 — 04.10.2026

- Значок панели задач и запуск из неё явно привязаны к установленному NEXUS.
- Тестовые и рабочие запуски отделены от установленного приложения своим идентификатором Windows.
- Android остаётся на 0.7.4. Данные и сервер не менялись.

## Windows / Android 0.7.4 — 04.10.2026

- Недельное сравнение называет показатель «Завершено дел» и показывает изменение словами: «На 2 больше», «На 2 меньше» или «Без изменений».
- Заголовок сравнения явно указывает на прошлую неделю. Расчёты и данные не менялись.

## Windows / Android 0.7.3 — 04.10.2026

- Оформление «Доминион» обновлено по документу 3.1: стальные рамки, согласованные панели и навигация, адаптация к узким экранам.
- В шапку «Сегодня» добавлен выбранный арт Thor. Изображение хранится в приложении, загрузка из интернета не требуется.
- Удалён отдельный «Вопрос вечера». Вечерний распорядок с уходом и записью дневника сохранён.
- Стандартная тема и данные пользователей сохранены. Обновление сервера не требуется.

## Windows / Android 0.7.2 — 04.10.2026

- Дневной и недельный наставник учитывает исходные тексты дневника, комментарии к операциям, тренировкам и инвестициям, цели, планы, уход, показатели и рабочие записи.
- Наставник различает записи пользователя, подтверждённые операции, планы и материалы ИИ. Переводы между счетами не считаются расходами, пополнения портфеля — прибылью.
- Тексты дневника хранятся 30 дней с момента записи. В интерфейсе по-прежнему видны последние три.
- Обновите все устройства: прежние версии продолжают оставлять только три текста. Уже удалённые тексты не восстанавливаются.
- Обновление сервера не требуется.

## Windows / Android 0.7.1 — 04.10.2026

- Убраны слайдеры под графиками в обеих темах. Выбор даты доступен по наведению, касанию и стрелкам клавиатуры.
- Вес на графиках «Доминиона» использует десятичную запятую.
- Дополнены вторичные подписи «Доминиона»: вечерний вопрос, поле воспоминания и подтверждение сохранения досье.
- Экранный диктор получает направление и оценку дельты отдельно, включая изменение относительно цели.

## Windows / Android 0.7.0 — 04.10.2026

- Добавлено оформление «Доминион»: стальные панели, красные акценты, новая навигация и короткие системные названия. Стандартная тема сохранена.
- Смена темы сохраняет черновики, открытые окна, выбранные точки графиков и выполняющийся разбор ИИ. Выбор хранится на устройстве.
- Обновлены графики и сравнение веса/сна: даты, шкала, пропуски, точные суммы и корректный ноль.
- Адаптация Android к узким экранам, системному размеру текста и кнопке «Назад»; тактильный отклик учитывает системные настройки.
- Обновление сервера не требуется. Linux остаётся на прежней версии.

## Linux 0.4.5 — 01.10.2026

- Добавлена переносная сборка AppImage x86_64 без установки приложения.
- Автозапуск Linux ссылается на исходный AppImage; настройка Windows сохраняет прежнее поведение.
- Секреты защищены системной связкой ключей; небезопасный Linux backend `basic_text` отклоняется.
- Добавлены иконка окна Linux, пересборка SQLite и проверка упакованного приложения в Linux CI.
- Windows продолжает распространяться через обычный установщик; Android-сборка этого обновления не требуется.
- Первая Linux-сборка требует проверки на компьютере пользователя.

## Windows 0.4.4 / Android 0.2.6 — 01.10.2026

- Исходники обоих приложений и сервера собраны в одном публичном репозитории под MIT.
- Убраны декоративные LOCAL и «Локальная система».
- Выровнены финансовые карточки; ненужные доступы можно скрывать и возвращать в список.
- Подтверждения Windows переведены в диалоги приложения, настроен фокус полей.
- Наставник получает инструкцию использовать нецензурную лексику и реагировать на манеру пользователя.
- По умолчанию используется экономичный набор моделей ИИ; ручной выбор оставлен владельцу.
- В публичных сборках отсутствует адрес сервера автора. Для нового подключения требуется собственный HTTPS-адрес.
- Резервное копирование приложения средствами Android отключено.
- Добавлены проверки Windows, Android и сервера, обновляющий серверный скрипт с откатом.

Релиз проверен локальными тестами и сборками; не заменяет внешний аудит безопасности и проверку на каждом физическом устройстве.
