# Безопасность и личные данные

В репозитории находятся код, ресурсы интерфейса и вымышленные тестовые данные. Базы пользователей, приглашения, действующие ключи, серверное окружение и ключи подписи не публикуются. `.gitignore` — дополнительная защита; перед публикацией необходима проверка содержимого и истории.

## Границы защиты

- Сервер работает на localhost за HTTPS-прокси. Данные каждого приглашённого профиля, ключи, копии и уведомления изолированы. Администрирование доступно владельцу.
- Данные синхронизации сервер может читать. Дополнительные копии шифруются на устройстве отдельной фразой.
- Management API Key OpenRouter хранится только на ПК владельца в системном защищённом хранилище; гостям выдаются персональные ключи. Месячный лимит проверяет OpenRouter.
- Локальные профили Windows не заменяют отдельные учётные записи ОС. Человек с доступом к той же учётной записи может переключать профили.
- На Android подключение хранится на устройстве, рабочий AI-ключ не возвращается в React. Резервное копирование приложения средствами Android отключено.
- В CI не нужны пользовательские базы или рабочие ключи. Автоматические проверки не подключаются к рабочему VPS и не выполняют платных запросов ИИ.

Проект не проходил внешний аудит безопасности. Проверка на опубликованные секреты не означает отсутствия всех возможных уязвимостей.

## Сообщения об уязвимостях

Не размещайте ключи, приглашения, личные базы и подробности эксплуатации в публичных Issues. Используйте приватное сообщение владельцу или GitHub Private vulnerability reporting, если оно включено для репозитория. Случайно опубликованный секрет нужно отозвать; удаления файла из текущей версии недостаточно.
